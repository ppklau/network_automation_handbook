# Templates

Reusable templates for executive, technical, and operational use. Each template is designed to be immediately usable — adapt the ACME Investments example data to your own environment.

## Priority Templates (v1)

These are the first templates to be developed at high quality:

1. **[technical/source-of-truth-schema.yml](technical/)** — YAML-based SoT schema, extending the ACME Investments structure
2. **[technical/ci-cd-pipeline-template.yml](technical/)** — GitLab CI / GitHub Actions pipeline, extending the Batfish demo
3. **[executive/business-case.md](executive/)** — Executive-ready business case with ROI tracking
4. **[executive/stakeholder-map.md](executive/)** — Stakeholder mapping and value hypothesis template
5. **[technical/architecture-decision-record.md](technical/)** — ADR template for documenting transformation decisions
