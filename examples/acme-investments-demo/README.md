# ACME Investments — Network Automation Demo

The primary worked example for the handbook. A production-representative network-as-code implementation for a fictional financial services firm operating under MiFID II, FCA SYSC, and PCI-DSS.

## What This Demonstrates

- The three-layer intent model: `requirements.yml` → `design_intents.yml` → `nodes.yml`
- Multi-vendor template library: Arista EOS (spine-leaf) + Cisco IOS (branch)
- Ansible configuration generation pipeline
- Nine-stage GitLab CI pipeline from lint to deployment
- Pipeline artefacts as compliance audit trail

## Network Topology

```
lon-dc1 (Primary Datacentre — London)
  Arista EOS
  ├── spine01 (ASN 65001)  ── spine02 (ASN 65002)
  ├── leaf01/leaf02 (MLAG pair, ASN 65101/65102)
  └── border-leaf01/border-leaf02 (MLAG pair, ASN 65201/65202)

lon-branch1 (Branch Office — London)
  Cisco IOS
  ├── lon-branch1-rtr01 (WAN router, OSPF)
  └── lon-branch1-sw01  (Access switch)
```

**Security zones:** TRADING (VLAN 100/VNI 10100), CORPORATE (VLAN 200/VNI 10200), DMZ (VLAN 300/VNI 10300)

## Directory Structure

```
acme-investments-demo/
├── requirements.yml          # Layer 1: business and regulatory requirements
├── design_intents.yml        # Layer 2: testable architecture decisions
├── inventory/
│   ├── inventory.yml         # Ansible inventory (hosts + groups)
│   └── nodes.yml             # Layer 3: source of truth (all device data)
├── templates/
│   ├── arista_eos/
│   │   ├── spine.j2          # Arista EOS spine template
│   │   └── leaf.j2           # Arista EOS leaf/border-leaf template
│   └── cisco_ios/
│       ├── wan_router.j2     # Cisco IOS branch router template
│       └── access_switch.j2  # Cisco IOS branch switch template
├── playbooks/
│   └── generate_configs.yml  # Ansible playbook — renders all configs
└── .gitlab-ci.yml            # Nine-stage CI pipeline
```

Generated output (not committed — regenerated by pipeline):
```
generated/

├── spine02.cfg
├── leaf01.cfg
├── leaf02.cfg
├── border-leaf01.cfg
├── border-leaf02.cfg
├── lon-branch1-rtr01.cfg
└── lon-branch1-sw01.cfg
```

## Prerequisites

- Python 3.10+
- Ansible 6+ with `ansible.netcommon` and `arista.eos` / `cisco.ios` collections
- `yamllint`, `ansible-lint`
- Batfish Docker image (for validation stage)
- `napalm` (for deployment stage)

## Quick Start

```bash
# 1. Validate YAML structure
yamllint inventory/nodes.yml design_intents.yml requirements.yml

# 2. Generate all device configurations
ansible-playbook playbooks/generate_configs.yml -i inventory/inventory.yml

# 3. Inspect a generated configuration
cat generated/spine01.cfg
cat generated/lon-branch1-rtr01.cfg
```
